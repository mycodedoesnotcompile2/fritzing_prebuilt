Fritzing prebuilt
-----------------

Description
------------
The great ["Fritzing"](https://github.com/fritzing/fritzing-app/) tool in prebuilt versions.

Building workflows are [there](https://github.com/mycodedoesnotcompile2/fritzing_prebuilt/blob/main/.github/workflows/).

See the [Github release page](https://github.com/mycodedoesnotcompile2/fritzing_prebuilt/releases) of this repository to access prebuilt binaries for different targets.  
=> Currently, only Linux x64, but I am working on other ones.
